**Obesity Level Classification**
This project aims to predict obesity levels based on individual lifestyle and physiological features using supervised machine learning. It was completed as part of a university data science course project.

🧠 **Problem**
The goal is to classify individuals into one of seven obesity categories (from underweight to extreme obesity) based on attributes such as age, diet, physical activity, and habits.

🔧 **What We Did**
Cleaned and prepared the dataset

Performed exploratory data analysis (EDA)

One-hot encoded categorical features

Trained several classification models (e.g., Random Forest, Gradient Boosting)

Tuned hyperparameters to improve macro F1-score

Evaluated models with a focus on imbalanced classes

🚀 **What We Learned**
This project strengthened our skills in:

Handling class imbalance

Feature encoding and preprocessing

Model selection and comparison

Evaluation with appropriate metrics (macro F1-score)

Experiment tracking and result analysis

We also gained experience in working through a complete ML pipeline — from raw data to final model evaluation.

📦 **Tools & Libraries**
Python

pandas, NumPy

scikit-learn

Jupyter Notebook

📈 **Evaluation**
We used macro F1-score as the primary evaluation metric to ensure fair performance across all obesity classes.
Achieving a final kaggle submission score of **_0.9665_**
